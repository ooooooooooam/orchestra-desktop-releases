## First launch

**macOS:** this build isn't notarized by Apple yet. The first time, right-click Orchestra in Applications and choose **Open**. If macOS still blocks it, go to **System Settings → Privacy & Security** and click **Open Anyway**.

**Windows:** if SmartScreen appears, click **More info → Run anyway**.

**Linux AppImage:** make it executable first: `chmod +x Orchestra_amd64.AppImage`.
